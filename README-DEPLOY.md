# دليل النشر والاستضافة — مركز المهندس الشامل (نسخة Pro)

> نظام كامل: متجر + لوحة تحكم احترافية + API + قاعدة بيانات حقيقية.
> **صفر مكتبات خارجية** — يشتغل بأي Node 22+ بدون `npm install`.

---

## 1. التشغيل المحلي (جرّبه فوراً)

```bash
node server/server.js
```

| الرابط | الوصف |
|---|---|
| `http://localhost:3000/` | المتجر |
| `http://localhost:3000/admin` | لوحة التحكم Pro |
| `http://localhost:3000/api/health` | حالة الـ API |

- كلمة المرور الافتراضية: `admin12345` ← **غيّرها من اللوحة: الإعدادات → تغيير كلمة المرور**
- قاعدة البيانات تُنشأ تلقائياً في `data/mohandis.db` مع بيانات تجريبية (تُحذف بزر واحد من الإعدادات)

## 2. ليه الطلبات كانت مش بتظهر؟ (السبب الجذري — تم حله)

| # | المشكلة القديمة | الحل الجديد |
|---|---|---|
| 1 | الطلبات كانت تتخزن في `localStorage` = **لكل جهاز لوحده** | طلب العميل بيتخزن في **قاعدة بيانات على السيرفر** — اللوحة تقرأ منها من أي جهاز |
| 2 | مزامنة CrudCrud القديمة: سيرفرهم رد **`Endpoint has expired`** (انتهت صلاحيتها) | نظام API خاص بك — لا يعتمد على طرف ثالث |
| 3 | الدالة `refreshFromCloud` في اللوحة القديمة **لم تكن معرّفة أصلاً** (`ReferenceError`) → لم تجلب أي شيء | لوحة جديدة تجلب كل 4 ثوانٍ + مؤشر اتصال لحظي + إشعار بصوتي عند الطلب الجديد |
| 4 | لا يوجد رقم طلب (Ref) ولا حالات متابعة | كل طلب له رقم `ORD-YYYYMMDD-XXX` +7 حالات + ملاحظات داخلية |

## 3. الاستضافة (Hosting) — مقارنة 2026 💰

> المشروع الآن **سيرفر Node + قاعدة بيانات** → Vercel القديم **لا يصلح** له (Vercel للاستقبال الساكن/الـ Serverless فقط، وبيوقف السيرفرات الطويلة).

| الاستضافة | السعر | مناسبة لـ | المزايا | العيوب |
|---|---|---|---|---|
| **Render** (مجاني) | $0 | تجربة سريعة | سهل، نشر من GitHub، HTTPS مجاني | بينام بعد ~15 دقيقة خمول → أول زيارة تتأخر ثوانٍ |
| **Render Starter** ⭐ | $7/شهر | البداية الجادة | بدون نام، فواتير ثابتة، مراقبة، نسخ احتياطي DB مدفوع | أغلى قليلاً |
| **Railway** | $5/شهر + استهلاك | مرونة | أسرع نشر، يتكيف مع الحمل | الفاتورة بتزيد مع الاستهلاك |
| **Hetzner VPS** ⭐⭐ | ~€6.5/شهر | **الاحترافي الكامل** | تحكم 100%، أداء ممتاز، قريب من مصر/الشرق الأوسط (EU) | يحتاج إعداد بسيط (Docker أو PM2) |
| **Hostinger VPS** | $5.99/شهر | بديل رخيص | سيرفر خاص، دعم عربي | إعداد يدوي |
| **Fly.io** | ~$2+ | تكلفة قليلة | نشر Docker سهل | تسعير_usage قد يفاجئك |
| ~~Vercel~~ | — | ❌ لا يصلح الآن | — | لا يشغّل Node server دائم |

### توصيتي العملية (بالتسلسل):

1. **اليوم للتجربة:** Render الخطة المجانية — 5 دقائق ويشتغل.
2. **لو هتشتغل بجد بدون وجع راس:** **Render Starter ($7)** أو **Railway ($5)** — كله مُدار، تدفع وتنام مرتاح.
3. **الأنسب احترافية وتكلفة (هذا ما أنصح به):** **VPS (Hetzner أو Hostinger) + Docker + Caddy** — تحكم كامل، سرعة عالية، وتكلفة ثابتة ~$6. نسخة `Dockerfile` جاهزة في المشروع.
4. **لو عندك دومين من قبل:** اربطه بأي خيار أعلاه — Render/Caddy يعطونك **HTTPS مجاني تلقائياً**.

> 💳 طرق الدفع: Render/Railway/Hetzner يقبلون البطاقات الدولية وPayPal — تحقق من المتاح لديك قبل الاشتراك.

### خطوات النشر على Render (بالتفصيل — 5 دقائق):

1. ارفع مجلد `mohandis-pro` على **GitHub** (أو من داخل Render: اسحب الملفات).
2. [render.com](https://render.com) → **New → Web Service** → اربط المستودع.
3. اضبط:
   - **Runtime:** Node
   - **Build Command:** *(اتركها فارغة)*
   - **Start Command:** `node server/server.js`
4. **Environment Variables:**
   - `ADMIN_PASSWORD` = كلمة مرور قوية (بدون مسافات)
   - `SEED_DEMO` = `0` (بعد ما تمسح البيانات التجريبية يدويًا — أو اتركها لتشوف اللوحة مليانة)
5. **Create Web Service** → خلال دقيقة يعطيك رابطاً مثل `https://mohandis.onrender.com`.
6. افتح `/admin` وسجّل الدخول → **الإعدادات → غيّر كلمة المرور فوراً**.
7. (اختياري) من **Settings → Custom Domain** اربط دومينك.

### النشر على VPS بـ Docker (الخيار الاحترافي):

```bash
# على السيرفر (Ubuntu/Debian)
apt update && apt install -y docker.io docker-compose-v2
git clone <repo> && cd mohandis-pro

docker build -t mohandis .
docker run -d --name mohandis --restart always \
  -p 80:3000 \
  -v mohandis-data:/app/data \
  -e ADMIN_PASSWORD='كلمة-قوية-هنا' \
  mohandis
```

مع **Caddy** أمامه للـ HTTPS المجاني:

```
# Caddyfile
your-domain.com {
    reverse_proxy localhost:80
}
```

(أو استخدم `docker-compose.yml` مع caddy — نفس الفكرة.)

## 4. قاعدة البيانات (Database) 🗄️

### الحالية: SQLite — «قاعدة بيانات محترمة» فعلاً

| | |
|---|---|
| النوع | قاعدة بيانات حقيقية (ليست ملفات نصية) — محرك مدمج في Node |
| السرعة | قراءات في اللقطة (~1ms) — أسرع بكثير من أي استدعاء شبكة |
| الحجم | آلاف الطلبات سنوياً = كيلوبايتات فقط — **تكفي لمتجرك بمرات** |
| الإعداد | **صفر** — تُنشأ تلقائياً |
| المتانة | وضع WAL = آمن مع الكتابة المتزامنة + ملف واحد سهل النسخ |
| المكان | `data/mohandis.db` |

**النسخ الاحتياطي (مهم!):** الإعدادات → «تصدير نسخة كاملة» (JSON) أسبوعياً، واحتفظ بنسخة من ملف `data/mohandis.db` في مكان آمن (Google Drive / Backblaze).

### عند التوسع: PostgreSQL — الخطوة القادمة

| المزود | المميزات | مناسب لـ |
|---|---|---|
| **Neon** ⭐ | مجاني **دائم**، بدون بطاقة، ينمو معك، فروع DB | أفضل PostgreSQL مجاني 2026 |
| **Supabase** | مجاني + تخزين + مصادقة + Realtime | لو عايز باقة متكاملة (يقف بعد أسبوع خمول) |
| **Postgres على نفس الـ VPS** | تحكم كامل، بلا حدود | عند توفر VPS أصلاً |

- مخطط الجداول جاهز للتحويل في **`docs/schema.sql`** (أسماء الأعمدة متطابقة).
- التحويل يحتاج إضافة دراير `pg` وتعديل طبقة الاستعلامات في `server.js` (~نصف ساعة عمل) — لا تفعله إلا عند تجاوز SQLite حدوده (آلاف الطلب يومياً أو عدة مسائليين لنفس القاعدة).

> الخلاصة: **SQLite الآن = القرار الصحيح والمحترم لحجم متجر واحد. PostgreSQL عندما تتوسع.**

## 5. الأمان ✅

- كلمة مرور اللوحة **مشفّرة بـ scrypt** في قاعدة البيانات (وليس نصاً في الكود) — غيّرها من الإعدادات.
- تغيير كلمة المرور يُسقط جلسات كل الأجهزة الأخرى تلقائياً.
- الطلبات والاستلام **محدودة** ضد الإرسال المتكرر (Rate Limit) + تحقق من صيغة الرقم المصري.
- قراءة الطلبات/الصيانة تتطلب تسجيل دخول — الزوار يرون المنتجات فقط.
- HTTPS: فعّله من الاستضافة (Render تلقائي / Caddy على الـ VPS).
- واتساب الإشعارات يعمل كخط إضافي كما كان — لكن **اللوحة الآن لا تعتمد عليه أصلاً**.

## 8. الأسئلة الشائعة

**س: هل الطلبات القديمة (localStorage على موبايلي) هتروح؟**
ج: من الإعدادات → «استيراد ملف» — صدّر النسخة من اللوحة القديمة (JSON) واستوردها هنا. (مزامنة CrudCrud القديمة انتهت صلاحيتها من طرفهم فلم يكن هناك شيء في السحابة.)

**س: واتساب لسه بيشتغل؟**
ج: أيوه — كل طلب لسه بيبعت إشعار لوحة الواتساب زي ما هو، لكن أصبح **إضافياً**؛ المصدر الأساسي للعرض أصبح قاعدة البيانات.

**س: أضيف منتج من موبايلي وهيظهر للزوار؟**
ج: أيوه — أضفه من اللوحة (تبويب المنتجات) ويظهر في المتجر فوراً لأن المنتجات الآن من نفس القاعدة.

**س: عايز أشغّل المشروع على جهاز في المحل طول اليوم؟**
ج: `node server/server.js` وافتح `http://localhost:3000/admin` — سيشتغل بلا إنترنت (الطلبات الداخلية فقط تُحفظ محلياً).
